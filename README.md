# 🗺️ Análise Espacial da Criminalidade no Brasil

Projeto acadêmico desenvolvido na disciplina de **Planejamento e Gestão de Projetos**, unindo Ciência de Dados e Machine Learning para pensar a segurança pública no Brasil.

---

## 📌 Sobre o projeto

Quem já tentou comparar dados de criminalidade entre estados ou municípios brasileiros sabe o quanto isso pode ser trabalhoso: as informações estão espalhadas em bases diferentes, com formatos que nem sempre conversam entre si.

Esse projeto nasceu justamente dessa dificuldade. A ideia é organizar esses dados e representá-los de forma espacial e visual, tornando mais fácil enxergar padrões geográficos e comparar indicadores entre regiões.

---

## ❓ Pergunta-problema

> Como dados públicos e técnicas de análise espacial podem ser utilizados para identificar e visualizar padrões de criminalidade entre diferentes regiões do Brasil?

---

## 🎯 Objetivo

Planejar e desenvolver uma solução capaz de organizar, analisar e apresentar espacialmente dados públicos de criminalidade no Brasil, preparando uma base para aplicação posterior de técnicas de análise de dados e Machine Learning.

---

## 💡 Proposta de valor

A ideia central é transformar números soltos em informação geográfica que realmente faça sentido:

- 🗺️ **Visual** — mapas que traduzem os dados em imagens claras;
- 📊 **Comparável** — indicadores lado a lado entre estados e municípios;
- 🖱️ **Interativa** — filtros e recursos que permitem explorar os dados;
- 📖 **Fácil de interpretar** — sem exigir conhecimento técnico prévio.

Na prática, isso significa usar mapas, filtros e gráficos para tornar os indicadores de segurança pública mais acessíveis a quem precisa entendê-los.

---

## 👥 Público-alvo

O projeto foi pensado para atender a diferentes perfis:

- 🏛️ **Gestores públicos**, que precisam de dados confiáveis para tomar decisões;
- 🔬 **Pesquisadores**, interessados em explorar os dados sob diferentes perspectivas;
- 🎓 **Estudantes**, que queiram aprender ou se aprofundar no tema;
- 👮 **Profissionais da área de segurança pública**;
- 🙋 **Cidadãos**, curiosos em entender melhor os indicadores da própria região.

---
